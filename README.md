# streamergoalbar
Gives you a small streamer goal bar written in html and javascript, runs on your local machine. You can place it anywhere obs allows you to place it. Written in linux with support for windows and mac.


You will need a userdata.json to run this, I've purposefully excluded it because I don't want you to have my data lol.

looks like this

{
  "TARGET": 0,
  "CB_EVENTS_TOKEN": "",
  "CB_USERNAME": "",
  "CB_TITLE": "My Goal"
}

If the first launch doesn't create this just paste this into a file named userdata.json and fill in your deets, it should work 🤷‍♀️
